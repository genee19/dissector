# Project Dissector

## Summary
Dissector is a tool designed to analyze various situations by digging deep into underlying reasons, making the entire web of reasoning visual and obvious. This clarity allows for the planning of necessary corrective actions.

## The Dissector Method
The core thinking method of this project is an extension of Toyota's "5 Whys" technique.

*   **Unlimited Depth:** Unlike the traditional "5 Whys", Dissector places no limit on the number of levels you can drill down.
*   **Visual Reasoning:** The goal is to create a visual representation of the causal chain or network.
*   **Action-Oriented:** The ultimate purpose of the dissection is to identify specific, actionable steps to correct issues or improve outcomes based on the root causes found.
*   **Recursive Analysis:** Each answer can be further questioned, branching out to fully explore all contributing factors.

## Project Structure
*   **`/src`**: Contains all source code for the Dissector tool.
*   **`/situations`**: Stores definitions for various situations to be dissected. Each situation will have its own subfolder within this directory.
